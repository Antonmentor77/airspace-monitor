# Исторические инциденты

`incidents.json` предназначен только для проверенных, уже опубликованных событий с задержкой.
Не добавляйте в него текущие удары, движение боеприпасов, оперативные координаты или непроверенные сообщения.

Одна запись:

```json
{
  "date": "2026-09-01T12:00:00Z",
  "type": "Инцидент",
  "loc": "Название региона",
  "region": "Страна или область",
  "lat": 0,
  "lng": 0,
  "detail": "Краткое описание и ссылка на опубликованный источник"
}
```
